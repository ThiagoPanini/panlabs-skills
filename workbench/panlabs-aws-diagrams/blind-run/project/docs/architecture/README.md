# Arquitetura

O registro das decisões que dão forma à plataforma, e o material que as sustenta.

Toda decisão que muda a forma do sistema — fronteira de conta, escolha de banco, protocolo entre dois serviços — entra aqui **antes** de entrar em produção. O que não está escrito aqui não foi decidido: foi feito, e a próxima pessoa herda o resultado sem o porquê.
